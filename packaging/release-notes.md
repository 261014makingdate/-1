번역 아래의 발음을 **한글로 읽을 수 있는 표기**로 바꿨습니다.

- 중국어: `你好` → **니 하오**
- 일본어: `こんにちは` → **콘니치와**
- 영어: `nice to meet you` → **나이스 투 미트 유**
- 태국어: `สวัสดี` → **싸왓디**
- 라오스어: `ສະບາຍດີ` → **싸바이디**
- 러시아어: `Привет` → **프리벳**

한글 발음은 근사 표기입니다. 성조·강세·장단음·고유명사 발음은 실제 소리와 차이가 있을 수 있습니다. 변환에 필요한 사전과 데이터는 실행 파일에 포함합니다.

### 다운로드

Windows 10/11 64비트에서 `Malmoa.exe`를 내려받아 실행하세요. Python 설치는 필요하지 않습니다. ZIP에는 실행 파일, 사용 안내, SHA256 및 진단 결과가 들어 있습니다.

번역에는 인터넷 연결이 필요하며 입력 문장은 Google 또는 보조 서비스 MyMemory로 전송됩니다. 무료 서비스에는 사용량 제한이 있습니다.

### 검증

Windows에서 테스트 42개와 실행 파일의 오프라인 검사를 통과하고, 실행 파일을 통해 6개 언어의 실제 번역 및 한글 발음 출력이 확인된 경우에만 게시합니다. ZIP의 `live-test.json`에서 번역과 한글 발음 검사 결과를 확인할 수 있습니다.
