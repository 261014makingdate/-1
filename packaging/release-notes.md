한국어를 중국어·일본어·영어·태국어·라오스어·러시아어로 번역하는 Windows PC 앱입니다.

### 다운로드 및 실행

- **Malmoa.exe**: Windows 10/11 64비트용 단일 실행 파일. 내려받아 더블 클릭하세요. Python 설치는 필요하지 않습니다.
- **Malmoa-Windows-x64.zip**: 실행 파일, 사용 안내, SHA256, 오프라인 진단 결과를 포함합니다.

번역에는 인터넷 연결이 필요하며, 입력 문장은 Google 번역 서버로 전송됩니다. 비공식 웹 엔드포인트를 사용하므로 요청 제한이나 서비스 변경으로 번역이 실패할 수 있습니다.

### 발음

발음은 로마자 또는 영어 IPA로 표시합니다. 한글 독음과 음성 재생은 포함하지 않습니다. 태국어·라오스어 간이 로마자 표기는 실제 발음과 성조에 차이가 있을 수 있습니다.

### 검증 범위

GitHub Actions의 Windows 환경에서 테스트 및 실행 파일의 오프라인 진단이 통과한 경우에만 게시합니다. 오프라인 진단은 화면 초기화, 작업 스레드, 번역 결과 표시와 6개 언어 발음 데이터를 확인합니다. 실시간 번역 성공 여부는 별도로 검증하지 않았습니다.
