v0.1.3은 Windows 연결 설정과 번역 응답 처리를 개선한 버전입니다.

한국어를 중국어·일본어·영어·태국어·라오스어·러시아어로 번역하는 Windows PC 앱입니다.

### 다운로드 및 실행

- **Malmoa.exe**: Windows 10/11 64비트용 단일 실행 파일. 내려받아 더블 클릭하세요. Python 설치는 필요하지 않습니다.
- **Malmoa-Windows-x64.zip**: 실행 파일, 사용 안내, SHA256, 오프라인 진단 결과를 포함합니다.

번역에는 인터넷 연결이 필요하며, 입력 문장은 Google 번역 서버로 전송됩니다. 비공식 웹 엔드포인트를 사용하므로 요청 제한이나 서비스 변경으로 번역이 실패할 수 있습니다.

### 수정 사항

- Windows의 신뢰 인증서 및 수동 프록시 설정을 사용합니다.
- API의 요청 제한(HTTP 429) 또는 연결 실패 시 일반 Google 웹 번역 경로도 사용합니다. 웹 번역에서 발음이 제공되지 않으면 앱의 발음 변환기를 사용합니다.
- 연결·인증서·요청 제한·시간 초과·응답 형식 오류를 구분해 표시합니다.
- 번역 결과의 발음 대신 한국어 원문의 발음을 읽던 오류를 수정했습니다.

### 발음

발음은 로마자 또는 영어 IPA로 표시합니다. 한글 독음과 음성 재생은 포함하지 않습니다. 태국어·라오스어 간이 로마자 표기는 실제 발음과 성조에 차이가 있을 수 있습니다.

### 검증 범위

GitHub Actions의 Windows 환경에서 테스트 21개, 실행 파일의 오프라인 진단, 실행 파일을 통한 6개 언어의 실제 번역·발음 검사가 모두 통과한 경우에만 게시합니다. ZIP의 `live-test.json`에서 실제 번역 검사 결과를 확인할 수 있습니다. 사용자 PC의 네트워크 설정에 따라 연결 문제가 남을 수 있으며 오류 코드로 원인을 구분할 수 있습니다.
